A zero-cost, GitHub/Vercel-ready React + Vite tool website.

1. Solar ROI Calculator
2. Home Loan EMI Calculator
3. Salary Take-home Calculator

7. Laptop Buying Budget Calculator

11. Attendance Calculator
12. Age Calculator

### Technical niche
13. Photon Energy Calculator
14. Numerical Aperture Calculator
15. Fibre V-number Calculator

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Push this folder to GitHub, then import the repository into Vercel.

## Monetization hooks

The UI contains clearly labelled placeholder areas for advertisements and affiliate/sponsor placements. Replace them only after you have the appropriate ad/affiliate approvals.

Important: cost estimates are illustrative calculators, not financial, medical, engineering, purchasing, or professional advice. Review formulas and local assumptions before publishing commercial claims.
